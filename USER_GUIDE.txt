AuraNada - User Guide
Version 3.2.0
========================================

1. About AuraNada
========================================
AuraNada is a free, open-source audio mastering studio for Windows.
It analyzes audio files, normalizes their loudness, and converts them
to the format, sample rate and metadata state you want. Everything
runs locally on your machine. FFmpeg is bundled with the installer,
so no external software is required.

AuraNada is safe for audio you already own. It does not bypass
provenance information or fingerprinting, and no file content is ever
uploaded anywhere.

----------------------------------------
2. Interface Overview
----------------------------------------
The window has a custom, frameless title bar. From left to right you
switch between three tabs:

  [Convert]   The main workspace: select audio, pick a profile,
              fine-tune settings and run the conversion.
  [Analyze]   Inspect technical information and metadata tags of any
              single file.
  [A/B Preview]  Compare the original file against the processed
              result before you commit to a conversion.

Window controls (minimize/close) are in the top-right corner.

----------------------------------------
3. Suggested Workflow
----------------------------------------
  1. Convert tab -> add your audio file or a whole folder.
  2. Pick a profile, or leave the current default profile as-is.
  3. Adjust format, bitrate and loudness in "Output Format & Quality".
  4. Adjust metadata mode, sample rate, true-peak ceiling and LRA in
     "Advanced Output". Toggle effects you want under "Effects".
  5. Press "Start". Wait for the batch to finish. Files are written to
     the output folder.
  6. Optional: use A/B Preview first to hear the exact result before
     converting.

----------------------------------------
4. Convert Tab
----------------------------------------
4.1 Choosing your source
- Mode: pick "Single file" to process one file, or "Folder" to
  process every audio file inside a folder. Folder mode also imports
  a "names.txt" file if present. Write one desired output name per
  line, matching the import order, and AuraNada uses those names for
  the output files.
- Audio files: shows the number of loaded files.
- names.txt: shows "Found (M names)" when a rename list is loaded.
- Song Name / Artist: optional tags written to the output metadata.
  Leave empty to keep this information unchanged.

4.2 Output folder
The output folder row shows where results are written. By default it
is a folder named "AuraNada_Output" created next to your source
(location depends on the chosen mode). Click the folder row to change
the destination.

4.3 Profiles
The Profile bar is the heart of the settings system. Everything you
adjust below lives in one profile.
- Built-in profiles: five ready-made starting points covering loud
  masters, natural ears, studio quality, untouched originals and
  maximum loudness.
- Create Profile: saves the current settings as a new, custom profile.
- Reset: restores the selected profile to its factory default values.
- Delete: removes the selected custom profile (built-ins cannot be
  deleted).
The selected profile is remembered and restored the next time you run
AuraNada.

4.4 Output Format & Quality
- Format: m4a, mp3, aac, wav, flac, ogg or opus.
- Bitrate: 320k, 256k, 192k or 128k (ignored for lossless formats
  such as wav/flac).
- LUFS target: the loudness you want the output normalized to
  (-9 to -23). Lower values are quieter. -14 is a good all-round
  listening level; use -16 for a more dynamic result, -23 for
  broadcast-style delivery.

4.5 Advanced Output
- Metadata: how tags are handled.
    "Clean + write core info"  - strips the source tags and writes a
                                 clean set of core tags (title, plus
                                 album and artist if you typed them).
    "Keep protected tags"      - keeps the source tags untouched and
                                 updates only the fields you typed.
    "Completely clear"         - removes all tag data from the output.
- Sample rate: 44100, 48000 or 96000 Hz.
- True Peak: upper ceiling for the true-peak level (-0.8, -1.0, -1.2
  or -2.0 dBTP). Stricter (lower) ceilings add safety margin against
  clipping on downstream players.
- LRA: Loudness Range in LU. Lower LRA = more consistent loudness;
  higher LRA = more dynamic. Choose from 7 to 17 LU.
- Normalization: "On (LUFS target)" applies 2-pass loudnorm to hit the
  LUFS target exactly; "Off (keep audio as-is)" leaves the level
  untouched and disables the LUFS target.

4.6 Effects
Effects are per-profile too. Toggle each one with its checkbox.
- Pitch / Tempo Micro-Adjust: pitch shift (-/+ 3.0 semitone-cents)
  and tempo change (up to +/- 0.50%) for creative tweaks. This is a
  creative tool only; it does not bypass provenance or fingerprinting.
- Stereo Widening: multiplies stereo width from x1.00 to x2.00.
  Values above x1.30 can sound phasey on headphones; use with care.
- Warmth EQ: a 250 Hz shelf boost (+0.5 to +5.0 dB) that removes
  digital harshness and adds organic warmth.
- Dynamic Compression: fixed gentle bus glue (threshold -18 dB,
  ratio 2:1, makeup +1.5 dB). Good for evening out level jumps.
- Room Reverb: adds a subtle space (0.10 to 1.00, intensity). High
  values cloud transients and slow material, so keep it low for
  speech or percussion.
- Tape Hiss: applies a tape-noise texture for a vintage feel. Keep it
  very low; 0.05-0.15 is the recommended range.

4.7 Running the conversion
- Start: begins processing all loaded files. The button shows a
  progress fill while the batch runs.
- Cancel: aborts the remaining files. Already-written files stay in
  the output folder.
- Reset (rotation symbol): clears the current file selection.
Progress is reported per file (e.g. "1/5  filename - converting").
If a file fails, the error is shown and processing continues with the
next file. A processing history is kept for the current session.

----------------------------------------
5. Analyze Tab
----------------------------------------
- "Select File & Analyze" opens a file dialog and shows technical
  information and metadata tags of the picked file: container/codec,
  duration, sample rate, channels, loudness info when available and
  the tag set.
- "Copy" copies the analysis report to the clipboard.
- "Clear" empties the report panel.
The drop area on top accepts a file by click as well.

----------------------------------------
6. A/B Preview Tab
----------------------------------------
Lets you hear "A (original)" against "B (processed)" before you
convert anything.
1. Select a file.
2. Choose the profile chip whose settings you want to test. Keep the
   default profile for what the Convert tab currently has.
3. Set the preview window: "Start (s)" and "Duration (s)" define which
   part of the file is rendered (default: from 0 s, 15 s long).
4. Press "Generate A/B". A temporary processed clip is rendered for
   the chosen selection.
5. Play each player below. A = original, B = processed result.
The temporary file is stored in the system temp folder and cleaned up
at startup, so nothing is left behind.

----------------------------------------
7. Settings Persistence
----------------------------------------
AuraNada stores its data in %APPDATA%\AuraNada\:
- settings.json   - the current defaults and last-used selection
- profiles.json   - your custom profiles
- history.json    - normalization/conversion history
Your profiles survive reinstalls as long as this folder is intact.
You can back up the whole folder to keep your setup.

----------------------------------------
8. Security & Privacy
----------------------------------------
- The app is fully offline: audio never leaves your computer.
- The window blocks external navigation and debugger injection and
  runs the UI with context isolation enabled.
- The source code is public under the MIT license, so behavior can be
  inspected.
- The official installer is not code-signed by a commercial issuer;
  Windows SmartScreen may ask you to confirm the first launch.

----------------------------------------
9. Troubleshooting
----------------------------------------
- "FFmpeg not found / FFmpeg badge missing": only relevant when
  running from source. Put ffmpeg.exe and ffprobe.exe in the project
  root and restart. The installer bundle already contains them.
- SmartScreen warning: the installer is unsigned. Choose "More info ->
  Run anyway". You can verify the binary hash against the release
  notes for extra confidence.
- Output folder in a protected location: choose a destination folder
  you can write to, such as Documents or Music.
- Antivirus alerts: since FFmpeg is bundled and the installer is
  unsigned, some scanners flag it. Whitelist the app after verifying
  the hash, or build from source yourself (see README).
- Files fail to convert: check the output format is supported,
  permissions on the output folder, and that the source file is not
  currently locked by another program.

----------------------------------------
10. Uninstalling
----------------------------------------
- Start Menu -> AuraNada -> "Uninstall AuraNada", or
- Windows Settings -> Apps -> AuraNada -> Uninstall.
The uninstaller removes the program. %APPDATA%\AuraNada keeps your
profiles and history; delete that folder manually if you also want a
clean reset.
